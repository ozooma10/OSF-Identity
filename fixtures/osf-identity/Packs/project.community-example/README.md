# Convention preset slot

Place a producer-round-tripped preset at
`Starfield.esm/0029A8EB.npc` to target that plugin-local tuple.

If the preset uses optional hair, beard, or other appearance mods, copy the
adjacent `Starfield.esm/0029A8EB.json.example` to
`Starfield.esm/0029A8EB.json` and list those dependencies. Never
fabricate or normalize the `.npc` payload.
