# Convention preset slot

Place a producer-round-tripped preset directly in this directory as
`Crew_ConstellationDaniel.npc` to target that NPC EditorID.

If the preset uses optional hair, beard, or other appearance mods, copy the
adjacent `Crew_ConstellationDaniel.json.example` to
`Crew_ConstellationDaniel.json` and list those dependencies. Never
fabricate or normalize the `.npc` payload.
