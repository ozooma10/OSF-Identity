# OSF Identity companion smoke pack

This is a directly installable convention-layout pack for live runtime testing.
It applies producer-exported Creation Kit fixtures to:

- Sarah Morgan — `Starfield.esm:00005983` — `HeadpartOnly.npc`, an
  unmistakable hair-only change.
- Andreja — `Starfield.esm:000059A7` — `Sarah.npc`, the full modified Sarah
  composite appearance.

Each target file is an exact copy of its named source under
`fixtures/osf-identity/Presets/CK`. The pack intentionally has no
`package.json`; the folder layout is the complete runtime assignment contract.
