# Convention preset slot

Place a producer-round-tripped preset here as `0029A8EB.npc` to target local
FormID `0029A8EB` from `Starfield.esm`. Do not use a load-order-prefixed FormID
or an EditorID as the filename.

If the preset uses optional hair, beard, or other appearance mods, copy the
adjacent `0029A8EB.identity.json.example` to `0029A8EB.identity.json` and list
those dependencies. Never fabricate or normalize the `.npc` payload.
